# tominurmi.net

A lightweight personal site built with HTML, CSS, and vanilla JavaScript. Click the robot to discover **Curiosity Lander**, a small lunar lander game with keyboard and touch controls.

[Visit tominurmi.net](https://tominurmi.net/)

## Files

- `index.html` — personal site.
- `curiosity-lander.html` — game page.
- `assets/lander.mjs` — game rendering and controls.
- `assets/lander-physics.mjs` — flight physics and landing rules.
- `tomi.svg` — robot avatar.
- `assets/fonts/` — self-hosted font and its license.
